## 📊 FrontendEncoder 详细架构

```
输入: (B, 512, 512, 32, T)  # 原始CTP 4D数据
  │
  ▼ Permute: (B, 512, 512, 32, T) → (B, 32, T, 512, 512)
  │
  ┌───────────────────────────────────────────────────┐
  │          3D Convolutional Block 1                 │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv3d(32→64, kernel=3x3x3, padding=1)     │  │
  │  │   参数: 32×64×27 = 55,296                  │  │
  │  │   输出: (B, 64, T, 512, 512)               │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm3d(64)                            │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU(inplace=True)                         │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │ (B, 64, T, 512, 512)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │          3D Convolutional Block 2                 │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv3d(64→128, kernel=3x3x3, padding=1)    │  │
  │  │   参数: 64×128×27 = 221,184                │  │
  │  │   输出: (B, 128, T, 512, 512)              │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm3d(128)                           │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU(inplace=True)                         │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │ (B, 128, T, 512, 512)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │      Adaptive Temporal Pooling                    │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ AdaptiveAvgPool3d((8, None, None))         │  │
  │  │   作用: 统一时间维度 T→8                    │  │
  │  │   T=20 → 8, T=21 → 8, T=22 → 8            │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │ (B, 128, 8, 512, 512)
  │
  ▼ Reshape: (B, 128, 8, 512, 512) → (B, 1024, 512, 512)
  │
  ┌───────────────────────────────────────────────────┐
  │          2D Convolutional Block                   │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv2d(1024→256, kernel=1x1)               │  │
  │  │   参数: 1024×256 = 262,144                 │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm2d(256)                           │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU(inplace=True)                         │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv2d(256→155, kernel=3x3, padding=1)     │  │
  │  │   参数: 256×155×9 = 357,120                │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm2d(155)                           │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU(inplace=True)                         │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │
  ▼
输出: (B, 155, 512, 512)  # 学习到的时空特征

总参数: ~895K
```

## 🔄 PriorFusionModule 详细架构

```
输入: (B, 5, 512, 512)  # 5个灌注参数图
  │  Channel 0: CBF  (脑血流量)
  │  Channel 1: CBV  (脑血容量)
  │  Channel 2: MTT  (平均通过时间)
  │  Channel 3: Tmax (达峰时间)
  │  Channel 4: TTP  (峰值时间)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         Prior Adaptation Block                    │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv2d(5→5, kernel=1x1)                    │  │
  │  │   作用: 学习灌注参数的线性组合              │  │
  │  │   参数: 5×5 = 25                           │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm2d(5)                             │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU(inplace=True)                         │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │
  ▼
输出: (B, 5, 512, 512)  # 适配后的先验特征

总参数: ~25
```

## 🧠 ModifiedResNet 详细架构

```
输入: (B, 160, 512, 512)  # 155(学习特征) + 5(先验特征)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         Modified Conv1 Layer                      │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Conv2d(160→64, kernel=7x7, stride=2, pad=3)│  │
  │  │   原ResNet: 3→64                           │  │
  │  │   修改后:  160→64                          │  │
  │  │   参数: 160×64×49 ≈ 502K                   │  │
  │  │   输出: (B, 64, 256, 256)                  │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ BatchNorm2d(64)                            │  │
  │  └─────────────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ ReLU + MaxPool(3x3, stride=2)              │  │
  │  │   输出: (B, 64, 128, 128)                  │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │ (B, 64, 128, 128)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         ResNet Layer 1                            │
  │   3 × Bottleneck(64→256)                         │
  │   输出: (B, 256, 128, 128)                       │
  │   参数: ~210K                                     │
  └───────────────────────────────────────────────────┘
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         ResNet Layer 2                            │
  │   4 × Bottleneck(256→512, stride=2)              │
  │   输出: (B, 512, 64, 64)                         │

  └───────────────────────────────────────────────────┘
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         ResNet Layer 3                            │
  │   6 × Bottleneck(512→1024, stride=2)             │
  │   输出: (B, 1024, 32, 32)                        │
  │   参数: ~7.1M                                     │
  └───────────────────────────────────────────────────┘
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │         ResNet Layer 4                            │
  │   3 × Bottleneck(1024→2048, stride=2)            │
  │   输出: (B, 2048, 16, 16)                        │
  │   参数: ~14.9M                                    │
  └───────────────────────────────────────────────────┘
  │ (B, 2048, 16, 16)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │      Global Average Pooling                       │
  │   AdaptiveAvgPool2d((1, 1))                      │
  │   输出: (B, 2048, 1, 1)                          │
  └───────────────────────────────────────────────────┘
  │
  ▼ Flatten: (B, 2048, 1, 1) → (B, 2048)
  │
  ▼
  ┌───────────────────────────────────────────────────┐
  │      Classification Head                          │
  │  ┌─────────────────────────────────────────────┐  │
  │  │ Linear(2048 → num_classes)                 │  │
  │  │   二分类: 2048×2 = 4,096 参数               │  │
  │  └─────────────────────────────────────────────┘  │
  └───────────────────────────────────────────────────┘
  │
  ▼
输出: (B, num_classes)  # 分类logits

总参数(ResNet50): ~24M
```

```
阶段1: 输入数据
├─ 原始CTP:      (4, 512, 512, 32, 22)  →  737 MB
└─ 灌注特征:     (4, 5, 512, 512)       →    5 MB

阶段2: FrontendEncoder (3D卷积)
├─ Permute:      (4, 32, 22, 512, 512)
├─ Conv3d_1:     (4, 64, 22, 512, 512)  →  1.82 GB
├─ Conv3d_2:     (4, 128, 22, 512, 512) →  3.65 GB
├─ Pool:         (4, 128, 8, 512, 512)  →  1.34 GB
├─ Reshape:      (4, 1024, 512, 512)    →  4.29 GB
└─ Conv2d:       (4, 155, 512, 512)     →  649 MB

阶段3: PriorFusionModule (轻量适配)
└─ Conv2d:       (4, 5, 512, 512)       →    5 MB

阶段4: 特征融合
└─ Concat:       (4, 160, 512, 512)     →  671 MB

阶段5: ModifiedResNet (ResNet50骨干)
├─ Conv1+Pool:   (4, 64, 128, 128)      →   17 MB
├─ Layer1:       (4, 256, 128, 128)     →   67 MB
├─ Layer2:       (4, 512, 64, 64)       →   34 MB
```

## 🔬 关键设计特点

### 1. **时间维度灵活性**
```python
AdaptiveAvgPool3d((8, None, None))
# T=20 → 池化到8个时间步
# T=21 → 池化到8个时间步
# T=22 → 池化到8个时间步
# T=30 → 池化到8个时间步
# 任意T都能处理！
```

### 2. **3D卷积捕捉灌注动态**
```
造影剂浓度变化曲线:
    ▲
    │     ╱╲      ← 峰值 (Peak)
浓度 │    ╱  ╲
    │   ╱    ╲___ ← 洗脱 (Washout)
    │__╱          ← 到达 (Arrival)
    └──────────────► 时间
    基线

3D卷积学习:
- 到达时间快慢 → 血流速度
- 峰值高低 → 血容量
- 洗脱速度 → 灌注状态
```

### 3. **双流特征融合**
```
学习特征 (155通道):  从原始数据自动学习
  +
先验特征 (5通道):    医学专家知识 (CBF/CBV等)
  =
融合特征 (160通道):  数据驱动 + 知识驱动
```

### 4. **预训练权重迁移**
```
ImageNet ResNet:     3通道RGB → 分类
                     ↓ 权重适配
CTP ResNet:          160通道医学图像 → 分类

适配方法:
pretrained_weight: (64, 3, 7, 7)
  → repeat & normalize
new_weight: (64, 160, 7, 7)
```

## 🎯 模型优势

1. **时间灵活性**: 处理任意时间点数量
2. **动态建模**: 3D卷积学习灌注曲线
3. **知识融合**: 结合数据驱动和专家知识
4. **迁移学习**: 利用ImageNet预训练权重
5. **端到端**: 从原始数据直接到分类结果
